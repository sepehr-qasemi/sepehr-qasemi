## 🎯 Core Principles in Agent Design

Every AI agent I design follows three non-negotiable principles:

> **1. Explicit Permission** — The agent never enters any site or performs any action without user approval.
>
> **2. Least Privilege** — Access is limited to exactly what the specific task requires, nothing more.
>
> **3. Full Transparency** — Every step the agent takes is visible to the user; nothing happens behind the scenes.
